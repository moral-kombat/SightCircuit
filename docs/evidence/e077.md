## What changed

- **Plan.** [Agent on Frame](../agent-on-frame.md) covers a fixed task runner,
  permission rules and a PreToolUse guard. It also defines three test tiers
  (unattended, wearer-present, never run by the agent), evidence provenance and
  a phased rollout. The PC-side fallback, option C, is marked as not ready as
  written.
- **Runner.** `framejacker/agent/runner.py` and `tasks.py`, standard library
  only, with the entry point `scripts/frame_agent_run.py`:
  - a fixed Tier A task table;
  - per-task timeouts that kill the whole process group; stragglers fail the
    task and are killed;
  - SIGINT, SIGTERM and SIGHUP kill the task group before the lock is
    released. A signal that arrives during task start is held, and a hangup
    the runner inherited as ignored (under `nohup`) stays ignored;
  - a run lock, a run budget and a `result.json` whose `clean` is `null`
    (not known) when git status fails, never true; the PR description says
    false, but `checkout_state` at `5e9f672` records `null`;
  - `update REVISION` takes a full commit hash. After a fetch it detaches a
    clean checkout at that commit only if the commit is already on
    `origin/main`, has the runner and guard files, and has a guard at least as
    strict as the running one (`GUARD_VERSION`). It refuses on any git error or
    timeout.
- **Guard.** `framejacker/agent/guard.py`, entry point
  `scripts/frame_agent_guard.py`:
  - it fails closed: any error exits 2, and the hook command ends in
    `|| exit 2`;
  - Bash and Monitor may run only the plain runner commands;
  - Read, Grep and Glob stay inside the checkout and away from private images,
    recordings and credentials. A path with leading or trailing white space
    or U+FEFF, or a leading `~`, is refused rather than reinterpreted, as is a
    `Glob` pattern containing `..`. Any other path, `..` included, is resolved,
    following symlinks, and must stay inside the checkout;
  - the agent may write only
    `artifacts/agent-runs/<runner-named run>/summary.md`, so it cannot change
    runner evidence.
- **Settings template.** `framejacker/agent/frame-settings.json` uses
  `dontAsk`, has no bare Read, Grep or Glob allow rules, denies reads of
  private data and allows runner-only Bash.
- **Phase 0 installer.** `scripts/frame_claude_install.sh` runs guided,
  bounded stages:
  - the signature stage accepts a manifest only with a `GOODSIG` and a
    `VALIDSIG` from the pinned release key, and rejects revoked or expired keys
    and bad signatures;
  - traps remove the throwaway keyring, its agent and its socket directory;
  - downloads are HTTPS-only, including redirects.
- **Tests.** `tests/test_frame_agent.py`, `tests/test_frame_claude_install.py`
  and `tests/test_frame_agent_commands.py`, which parses every Tier A command
  with its script's real parser. All three are on CI's no-skip list.
- **Test margin fix** (`5482f45`) for
  `tests/test_display_expiry.py::test_shared_sink_forwards_original_absolute_deadline`.
  The bridge drops an expiring frame that arrives after its deadline and sends
  no expiry event, and the test's 200 ms deadline through the client's writer
  thread failed once under full-suite load. The test now uses a 1 s deadline
  and a 5 s wait; its assertions are unchanged.

## Open decisions (owner)

These are not defects. They are documented in
[agent on Frame](../agent-on-frame.md) and
[on-device](../on-device.md#run-automated-checks-with-an-on-device-agent):

- A task that calls `setsid()` leaves the process group, so the runner does
  not contain it. Options: a systemd scope, a subreaper, or accept it.
- The guard routes only some tools; everything else is left to `dontAsk` and
  the allow list.
- `tier-a/service-preflight` and `service-report` exit non-zero on today's
  runtime by design, so `run-tier tier-a` never reports all-passed.
- There is no unpaced-replay task.
- The `dontAsk` read rules, and deny rules acting as search exclusions, are
  not confirmed in a live Claude Code session on Frame.
- The signature stage's handling of a `claude` on `PATH` that is a launcher
  other than `versions/<version>`: record it, warn, or fail.

## Review cycle 3 follow-ups (minor and nit; none blocking)

- `check_glob` picks a different search directory than Claude Code for a
  pattern that ends in `/` or has a backslash before its first glob character.
- `update`: a hangup or SIGTERM can release the lock while git is still
  running, and an immediate SIGKILL of git can leave a stale
  `.git/index.lock`.
- Installer: a signal during `drop_keyring` can re-enter the trap after
  `GNUPGHOME` is unset, and an interrupt during the downloads leaves its
  temporary directory behind.
- Docs: "git never prompts" overstates what `GIT_TERMINAL_PROMPT=0`
  guarantees.
- Tests: the class cleanup order leaves a socket directory behind, and one
  second-signal test assumes a 0.5 s timing.
