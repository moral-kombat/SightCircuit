## Why

SteamOS 0.5.8 removed Python 3.12 from the Frame and left `.venv-replay` with a
dangling interpreter ([E85](e085.md)). The owner chose a pin review for Python
3.14 before any rebuild; the review merged as SightCircuit PR #7 (main
`fe2e10f`): two pins move for Python 3.14 (numpy 2.2.6 to 2.3.2,
opencv-python-headless 4.12.0.88 to 4.13.0.90) behind environment markers, the
rest unchanged. The aarch64 wheels had been checked for existence on PyPI only;
this rebuild is their first run on the Frame.
