## Findings

- The variants cannot separate anything on this image: all five runs fed
  each model exactly the same bytes. The still is already grey, so swapping
  red and blue or replicating grey changes nothing; it is under the 960 px
  resize limit, so skipping the resize changes nothing; and the mirror-preview
  conversion of a preview is the preview itself. The identical scores say
  nothing about the cause of the miss.
- MobileNet-SSD no longer reports the `bottle` that E61 recorded at 0.926.
  The detector code has changed since E61 (one change is `d8f2cb9`, the SSD
  channel centring from E73); whether that change accounts for it is untested.
- YOLOX-Nano's best TV score was 0.427, below the unchanged 0.5 threshold. E61
  could not report this because the diagnostic did not exist.
