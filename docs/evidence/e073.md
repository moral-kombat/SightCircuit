# E73: Reproducible preprocessing audit and SSD channel correction

Date: 2026-10-31, Linux x86_64 cloud, Python 3.12.14, OpenCV 4.12.0,
NumPy 2.2.6, ONNX Runtime 1.31.0. Implementation commit `d8f2cb9`.
The approved E61 original still and independently supplied digest are absent;
no E61 reproduction or causal diagnosis was performed.

A generated constant BGR image (10, 80, 240) demonstrated that OpenCV's scalar
mean `127.5` centers only the first channel in the old SSD blob builder. The
old tensor was approximately `[-0.92155, 0.62744, 1.88232]`; the explicit
three-channel mean produces `[-0.92155, -0.37254, 0.88234]`. The package model
input and legacy demo adapter now share the corrected builder. A synthetic
regression verifies all channels and a separate geometry regression checks
realized per-axis box scaling after integer resize rounding. These are
independently demonstrated defects, not explanations of the E61 TV miss.

The existing evaluator now emits schema 3 with actual preprocessing tensor
hashes, source/model/runtime artifact hashes, grayscale/channel/crop policies,
SSD stretching, YOLOX letterboxing and inverse box mapping. Optional one-factor
`swap-rb`, `gray-replicated` and `native-size` comparisons retain their own
warm-up and results. `--require-input-digests` refuses an image without a
supplied reference digest; computing a digest alone is reported separately.
Annotation coverage distinguishes presence, absence and inspected boxes.

Executed commands included:

```bash
.venv/bin/python scripts/run_tests_no_skips.py tests/test_evaluation.py tests/test_detection.py
.venv/bin/python scripts/evaluate_detectors.py --fetch --audit-preprocessing \
  --require-input-digests --audit-variant swap-rb --audit-variant gray-replicated \
  --audit-variant native-size --report artifacts/evaluation-audit-final.json
```

The focused suite passed 28 tests with zero skips, including both real YOLOX
backends. The seed audit exited 0 at threshold 0.5 with one warm-up per
detector/variant, excluded from measured inference. Baseline SSD hit 7/9
supported presence checks with two factual absent-label violations; YOLOX hit
12/12 with zero. The six seed images provide 12 presence checks, 24 absence
checks and no box annotations. Localization is unscored; seed results do not
select a Frame detector default. The default remains unchanged.

The ignored report retains the exact source, model and native runtime hashes;
system dependency libraries are explicitly outside its runtime hash scope.
The integrated seed comparison and smoke check are recorded in [E74](e074.md).
Private images, models and generated reports were not committed. WP1 still
needs approved original E61 bytes/reference digest and inspection; WP2 still
needs representative, factual Frame annotations, including the rug/sofa case.
