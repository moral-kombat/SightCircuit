## Python 3.12 removed by the update

On 0.5.8, `/usr/bin/python3` points to `python3.14` (pacman `python 3.14.3-1`);
`/usr/bin/python3.12` and `/usr/lib/python3.12` are gone; no `uv` or `pyenv` is
installed. `.venv-replay`, rebuilt at the move on 0.5.6 with `/usr/bin/python3.12`,
now has a dangling interpreter symlink; its 583 MB of 3.12 site-packages are
intact but unusable; `pyvenv.cfg` still says 3.12.3. There is no `.venv` on the
Frame. Consequence: every `.venv-replay/bin/python` command is blocked, including
`--analyze-still`, `checkpoint_manifest.py`, `hud_marker_check --validate`, the
observer and the guide's offline unit tests. The installer
(`scripts/frame_claude_install.sh`) uses only the system `python3` for a JSON
read and is not blocked. The owner chose on 12:50 EST to wait for a coder's
review of the replay and window pins for Python 3.14 on aarch64 before any
rebuild, and rejected for now a user-space Python 3.12 install. Findings are
from `ls`, `readlink`, `pacman -Q` and `cat`; nothing was run or changed.
