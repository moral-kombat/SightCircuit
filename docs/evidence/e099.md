## Limits

A device report relayed by a peer session, recorded as received. It shows
the proof of concept the owner asked for: on the Frame, SDK camera frames
were exported by the helper, imported on the GPU from UBWC buffers,
converted to BGR, read by the strict reader, and recognised by the detector
in a bounded run with no display and no saved image, with the passthrough
rule kept. It does not evaluate recognition quality: the detections were not
annotated, the scene was not controlled, the named target object (a bottle)
was not detected, and one label is likely false; chair recall is the C5/C6
evaluation's question. Only the left camera ran. Standby behaviour on headset
removal is still untested. Every gate in `sightcircuit/gates.py` stays
closed; the run is the E48-pattern use the owner classified on 2026-11-09.
