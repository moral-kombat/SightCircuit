## Key Decisions Made
- **Fresh public repository instead of rewriting in place**
  - Context: GitHub keeps old commits reachable through closed PRs, and 28 PR descriptions named agents.
  - Rationale: a new repository has no old objects, no agent-named branches, no PR text to scrub.
- **One author identity for every commit, no agent trailers, in SightCircuit going forward**
  - Context: the owner asked to anonymize "me and the agents used".
  - Rationale: the owner's instruction overrides the default attribution footer; new commits there carry
    no Co-Authored-By or Claude-Session lines (say if this should change).
- **Work branches rebuilt as one squashed commit each on the renamed main**
  - Rationale: rebasing pre-rename commits onto a renamed tree conflicts everywhere; the project squash-merges anyway.
- **Documents read by tests stay on the full CI route**
  - Context: PR #4 put `guides/frame-sessions.md` and `reference/hud-observation.md` on the docs-only route.
  - Rationale: #2's and #3's tests tie documented numbers to code; the guard test enforces the rule.
- **Item 3 carried over unrenamed and unrebased**: it conflicts with the merged bridge work; the
  integration steps are in the handoff. Owner's answer, via the coder: carry it over unfinished.
- **framejacker is the private test copy**: force-synced from SightCircuit main; private minutes apply there.
